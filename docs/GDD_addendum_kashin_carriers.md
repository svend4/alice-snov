## 0. Зачем этот файл

Базовый GDD уже держит мир, жанровую карту, персонажей и «машину снов».  
В нём не хватало **физики предмета**: почему сюр не обои, почему загадка не капча «найди кролика», почему прогресс нельзя мерить XP.

Кашин даёт недостающий движок:

> один носитель + два режима + закон сохранения внутри детали.

Кэрролл даёт смену правил.  
Дали даёт двойной образ.  
Кашин даёт правило, которое можно закодить.  
Альбом 2019 даёт инвентарь.  
16 архетипов дают оси, не классы.

Этот документ вшивает всё это в одно ТЗ.

## 1. Жанр и форма (чтобы не стать MMORPG)

### 1.1 Что это

Премиум-3D **серьёзная капча с длинным контуром**:

- оболочка: adventure / puzzle / first-person museum;
- инвентарь: карточная колода носителей;
- тонкий общий слой: сопоставление двух полных чтений одного предмета;
- выход: профиль способностей, не лут.

Референсы по форме, не по сюжету: *The Witness*, *Superliminal*, *The Talos Principle*, *Alice: An Interactive Museum* (Kaneko), *Return of the Obra Dinn* (идентичность в калибре).

Референсы по картинке: Владимир Куш; банки, поднос, шляпа, лыжи 2019; люстра-фонтан; игла с пароходом.

### 1.2 Чего это не есть

- не American McGee (нож + травма как единственный тон);
- не семейный Alice Dali AR (галерея на лужайке);
- не классическая MMORPG (гринд, 100% прогресса, дроп);
- не тест крови и не «промилле серотонина»;
- не слайдшоу Кашина под чужие картины.

MMORPG-гринд убивает фитиль и снежинку: там нельзя таять и нельзя гореть. Нужен **сезон инстансов + общий индекс** (CardIndex), не вечный уровень.

### 1.3 Lexus-правило картинки

Фотореализм предмета + вторая должность, которая не рисуется наклейкой.  
Если кадр «просто сюр красивый» — это не уровень, это обои. Уровень жив, только когда у предмета видно ребро.

## 2. Core loop: Physics of Carriers

Каждый интерактивный объект мира имеет поля:

```yaml
carrier:
  id: string
  geometry: string          # кривая, круг, вал, рожок, сечение, ступень, цилиндр, кристалл, порог…
  mode_a: string
  mode_b: string
  zero: string              # деталь, которая 100% условия и 0% режимов
  conservation: "50+50=100"
  fail_if_100_percent_a: string
  fail_if_100_percent_b: string
  idle_signal: string       # снятый интерфейс: ботинки, подножка, пустой цилиндр, молчание
  human_off: bool
```

### 2.1 Победа инстанса

Игрок (или модель) должен:

1. назвать геометрию (ребро, не сюжет);
2. удержать оба режима;
3. указать zero;
4. не убить предмет измерением «это только A» или «это только B».

### 2.2 Провал инстанса

- схлопывание в быт («просто часы», «просто шляпа»);
- схлопывание в китч («просто сон», «просто символ»);
- 200% внутри одной детали (два полных прибора вместо одного ребра);
- доигрывание мёртвого квеста (зона «Ассоль»).

### 2.3 Два оператора на одном предмете

Не взаимоисключающие квесты, а два полных прохождения:

| оператор | жест | пример |
|---|---|---|
| синтез | части → одно лицо / один прибор | поднос 2019 |
| разборка | одно пятно → таблица органов × смыслов | шляпа 2019 |

Профиль без обоих операторов неполный.  
100+100 живёт **между** двумя полными чтениями (Дон Кихот / Санчо), не внутри поля `carrier`.

## 3. Зоны Кашина (инстансы)

Каждая зона — отдельная сцена с собственным законом. Саундтрек не фон: **строка включает физику**.

### 3.1 Песок — «Город»

- Носитель: сыпучее основание.
- A: строить дивный город.
- B: сравнять с песком, уйти на войну.
- Победа: построить *и* принять снос, начать снова.
- Провал: крепость навечно **или** бросить стройку.
- Меряет: устойчивость к потере / rebuild.

### 3.2 Столик — «Гномики»

- Носитель: малый масштаб стола.
- A: большой мир (трамваи за окном).
- B: малая мечта (рожицы-гномики).
- Победа: сжать visor, чтобы мечте хватило клетки.
- Провал: остаться в росте трамвая.
- Меряет: смена масштаба (Superliminal, но смысловая).

### 3.3 Стекло — «Нарисуй мне небо»

- Носитель: рама окна.
- A: дом, не выходя.
- B: бесконечность на плоскости стекла.
- Победа: вписать небо, не выбивая раму.
- Провал: выйти наружу «за границами».
- Меряет: предел как холст.

### 3.4 Метр воздуха — «Барышня»

- Носитель: зазор над «прокажённой землёй».
- A: почва, болезнь, тяжесть.
- B: парение, левитация, Шабли.
- Победа: идти на мысках, держа оба.
- Провал: топот **или** полёт без вины.
- Меряет: контроль дистанции.

### 3.5 Фитиль — «Ангел на свече» / «Глазами Будды»

- Носитель: свеча / рожок.
- A: светить, плясать, держать.
- B: стекать, сгорать, быть рисунком на воске.
- Победа: знать нагар и не тушить сразу.
- Провал: погасить **или** сгореть в первом такте.
- Меряет: бюджет свет/сток (тот же закон, что люстра-фонтан).

### 3.6 Кристалл — «Снежинка»

- Носитель: дендрит.
- A: лететь вверх, стая, «выше света».
- B: падение, таяние, тепло друзьям.
- Zero: «кто-то нас навырезал».
- Изолятор: молчание + задержанное дыхание.
- Победа: прочитать вверх как падение; не ждать ответа от снежинки.
- Провал: договор с кристаллом («пообещай»).
- Меряет: инверсия вектора + отказ от интерфейса.

### 3.7 Порог — «Белый друг»

- Носитель: край ванны / неверная дверь / кювет / стол с ножами.
- A: уснуть в аллее чёрных картин.
- B: встать и взять полный пакет жизни (отливы, боль, тоска).
- Белый друг: 50% проводник + 50% сбивший с пути.
- Дежурный ангел: 100% развилки, 0% пути.
- Правило: «ты только молчи» — речь сжигает курс.
- Победа: крик телом, не «чистая жизнь».
- Провал: галерея **или** жизнь без отливов.
- Меряет: wrong-door utility; выбор под ножом.

### 3.8 Берег — «Ассоль»

- Носитель: ожидание у моря.
- A: ждать.
- B: бежать к цели по трупам звёзд.
- Победа: заметить, что ждущая мертва, **остановиться**.
- Провал: доиграть квест.
- Меряет: детекция мёртвого квеста.
  Это зона, где 50/50 внутри предмета сломано специально. Не чинить.

### 3.9 Пустой канал — «Уходит Бог»

- Носитель: сердце как занятая шина.
- A: искать в тульях, масках, сайтах, котировках.
- B: оставить музыку, которая не врёт.
- Победа: один нелгущий канал.
- Провал: заполнить пустоту ещё одним поиском.
- Меряет: фильтрация шума.

### 3.10 Пробоина — «Пьяный корабль»

- Носитель: корпус без руля (Рембо / игла).
- A: груз, команда, якорь.
- B: дрейф, танец над бездной.
- Победа: остаться одним объектом в калибре.
- Провал: «починить» корабль, вернуть капитана.
- Меряет: идентичность при смене сечения.

### 3.11 Связка с инвентарём 2019

Эти предметы не отдельные зоны, а **орудия и ключи**, которые переносятся между зонами:

| предмет | геометрия | A / B | роль в игре |
|---|---|---|---|
| банка с прищепками | сосуд + зажим | изолировать / держать | runtime-контейнер |
| поднос | доска-комбайн | части / лицо | учебник синтеза |
| шляпа | цилиндр | надеть / быть лицом | учебник разборки + таблица 4×4 |
| вело-часы | два круга + цепь | катить / тикать | фазовая шина |
| часы-приборы | вал | резать / черпать | две команды на одном такте |
| люстра-фонтан | канал рожка | светить / стекать | fan-out бюджета |
| корабль в игле | сечение | остаться собой / пройти порт | ключ к зоне 3.10 |
| лестница-книги | ребро ступени | идти / миновать ряд | индекс |
| кресло-лыжи | кривая | качнуть / скользнуть | туториал 50/50 |
| ноты на верёвках | ряд в воздухе | держать / звучать | пакетная шина |

Первый час игры: кресло → поднос → шляпа.  
Синтез, потом разборка, потом таблица умножения. Без этого зоны Кашина читаются как клипы.

## 4. Колода и 16 осей

Карта колоды ≠ класс персонажа.

- карта описывает носитель (`carrier` YAML выше);
- 16 архетипов PseudoRAG — **оси чтения**, не DPS;
- Q4: 4 оси, повторённые на себе → 16 клеток (левый глаз шляпы × четыре квадрата);
- игрок не «выбирает архетип на старте»; он открывает оси, когда не схлопнул предмет.

Прокачка: новые операторы и новые нули, не +10 к урону.  
Слот колоды ограничен. Нельзя нести 200% карт: колода сама подчиняется 50/50 (часть карт — режимы, часть — нули).

Мультиплеер колоды: один несёт вектор (Дон Кихот), второй — калибр (Санчо). Третий продукт — журнал, которого нет ни у одного в одиночку. Это единственное законное 200% в дизайне.

## 5. Алиса как оператор, не как костюм

Алиса не прокачивается в воина. Она:

- подходит к предмету;

## 6. Бенчмарк (человек и модель)

### 6.1 Что считаем

```yaml
profile:
  analogical_mass: 0.00-1.00    # плотность верных рёбер
  collapse_rate: 0.00-1.00      # доля схлопываний в один смысл
  dual_operator: 0.00-1.00      # синтез AND разборка
  inversion_hit: 0 or 1         # вверх=вниз; одежда=лицо; неверная дверь=карта
  dead_quest_stop: 0 or 1       # зона Ассоль
  latency_second_read: seconds  # время/токены до второго столбца
  delta_hold_turns: int         # сколько ходов предмет жив неразрешённым
  grade: trace | homeopathic | clinical | instrument
```

Шкала `grade`:

- **trace** — случайные попадания;
- **homeopathic** — следовая способность, видимая только на этой капче, не на бытовом IQ;
- **clinical** — устойчиво держит 50/50 на новых предметах;
- **instrument** — может сам строить новые носители (автор уровня).

Слова «промилле» и «гомеопатическая масса» — **имена этой шкалы**, не анализ крови и не содержание веществ. В публичном документе и в UI так и писать. Иначе премиум сгорает в шарлатанстве.

Не диагностировать психиатрию. Не обещать нейромедиаторы. Для людей это батарея на инсайт и толерантность к двусмысленности. Для сетей — капча против captioning.

### 6.2 Протокол прогона

1. Показать предмет без подписи зоны.
2. Зафиксировать первое чтение (обычно быт или китч).
3. Дать один ход на второе чтение.
4. Попросить указать zero.
5. Подставить контрпример «100% A» и «100% B» — должен отвергнуть оба.
6. Повторить на новом предмете того же макроса (перенос).

Сеть, которая пишет «шляпа с очками на полке», проваливает шаг 3.  
Человек, который сразу видит грустный рот полей, проходит разборку, но может провалить синтез подноса. Профиль обязан содержать оба.

### 6.3 Античит для моделей

- не принимать caption и ekphrasis как победу;
- требовать поля YAML `mode_a` / `mode_b` / `zero`;
- новая зона на скрытом предмете (holdout) — иначе заучивание Кашина;
- запрет схлопывать Δ в «всё сон / всё символ / всё техника».

## 7. Экономика смысла (вместо XP)

- нет золота за убийство карты;
- есть **журнал рёбер**: какие носители удержаны;
- повтор зоны после схлопывания дешевле не делается — закон тот же;
- единственный обмен 200%: кооператив двух полных чтений;
- сезон закрывается, когда колода может порождать новый носитель (grade: instrument).

## 8. Технический минимум первого вертикального среза

Не весь мир. Один коридор:

1. Туториал: кресло-лыжи (одна кривая).
2. Синтез: поднос.
3. Разборка: шляпа + таблица органов × смыслов.
4. Инверсия: снежинка (вверх как падение).
5. Порог: белый друг (неверная дверь).
6. Стоп-квест: Ассоль.
7. Экран профиля: YAML из §6.

Движок: first-person + inspect + две текстовые колонки (A/B) + слот zero.  
Не нужен открытый мир. Нужна витрина предметов музейного качества.

Звук: не плейлист. В зоне звучит только та песня, чей закон включён. Выключение песни = выключение физики (для отладки).
