## 3. Зоны Кашина

1. Песок — Город: строить / сносить.
2. Столик — Гномики: сжать масштаб.
3. Стекло — Нарисуй небо: рама как холст.
4. Метр воздуха — Барышня: дистанция.
5. Фитиль — Ангел / Будда: свет / сток.
6. Кристалл — Снежинка: вверх = падение.
7. Порог — Белый друг: неверная дверь = карта.
8. Берег — Ассоль: остановить мёртвый квест.
9. Канал — Уходит Бог: один нелгущий канал.
10. Пробоина — Пьяный корабль: идентичность в калибре.

Инвентарь 2019: кресло, поднос, шляпа, вело-часы, часы-приборы, люстра, игла, лестница, ноты.
Первый час: кресло → поднос → шляпа.
