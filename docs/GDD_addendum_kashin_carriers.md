## 0. Зачем этот файл

Базовый GDD уже держит мир, жанровую карту, персонажей и «машину снов».  
В нём не хватало **физики предмета**: почему сюр не обои, почему загадка не капча «найди кролика», почему прогресс нельзя мерить XP.

Кашин даёт недостающий движок:

> один носитель + два режима + закон сохранения внутри детали.

Кэрролл даёт смену правил.  
Дали даёт двойной образ.  
Кашин даёт правило, которое можно закодить.  
Альбом 2019 даёт инвентарь.  
16 архетипов дают оси, не классы.

Этот документ вшивает всё это в одно ТЗ.

## 1. Жанр и форма (чтобы не стать MMORPG)

### 1.1 Что это

Премиум-3D **серьёзная капча с длинным контуром**:

- оболочка: adventure / puzzle / first-person museum;
- инвентарь: карточная колода носителей;
- тонкий общий слой: сопоставление двух полных чтений одного предмета;
- выход: профиль способностей, не лут.

Референсы по форме, не по сюжету: *The Witness*, *Superliminal*, *The Talos Principle*, *Alice: An Interactive Museum* (Kaneko), *Return of the Obra Dinn*.

### 1.2 Чего это не есть

- не American McGee;
- не семейный Alice Dali AR;
- не классическая MMORPG;
- не тест крови;
- не слайдшоу Кашина под чужие картины.

Нужен **сезон инстансов + общий индекс** (CardIndex), не вечный уровень.

### 1.3 Lexus-правило картинки

Фотореализм предмета + вторая должность. Если кадр «просто сюр красивый» — это не уровень, это обои.

## 2. Core loop: Physics of Carriers

См. `schema/carrier.yaml`.

Победа: назвать геометрию, удержать оба режима, указать zero, не убить предмет измерением «только A» / «только B».

Провал: схлопывание в быт или китч; 200% внутри одной детали; доигрывание мёртвого квеста (Ассоль).

Два оператора: синтез (поднос) и разборка (шляпа). 100+100 только между двумя полными чтениями.

Полный разбор зон, инвентаря 2019, колоды, бенчмарка и вертикального среза — в локальной полной копии исходного аддендума (см. ниже по разделам 3–11 исходного файла в репозитории после догрузки полного текста).
