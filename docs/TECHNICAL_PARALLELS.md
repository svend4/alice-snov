# Technical Parallels — SURREAL → TECH

**Проект:** alice-snov  
**Слой:** обратный каргокульт  
**Закон:** одна геометрия несёт два режима; внутри детали 50+50=100  
**Дата:** 2026-09-22

Это не «символы». Это карта: *какая деталь мира уже является прибором*.

---

## 0. Оператор параллели

```
surreal_object
    → shared_geometry        # ребро, которое нельзя разрезать
    → mode_a                 # должность 1
    → mode_b                 # должность 2
    → zero                   # 100% условия, 0% режимов
    → midlevel_cluster       # шина / муфта / кластер среднего уровня
    → fail_100               # что будет, если оставить только одну должность
    → apparatus_name         # как это назвать инженеру
```

Средний уровень — не «квантовый компьютер целиком» и не «просто лыжа».  
Это **муфта на два процесса**, которая держит бюджет 50/50, а не 100+100.

## 2. Зоны Кашина → аппараты

### 2.1 Песок / «Город»
Кластер: **foundation-as-consumable**. Несущая сама расходный материал. Параллель: scratch-space диска; временный фундамент, который снимают вместе со зданием.

### 2.2 Столик / «Гномики»
Кластер: **scale coupler / visor**. MIP / Superliminal. Fail: масштаб трамвая или кукольность без окна.

### 2.3 Стекло / «Нарисуй небо»
Кластер: **viewport-canvas**. Окно ОС как холст, не как дверь. Выбить стекло = потерять framebuffer.

### 2.4 Метр воздуха / «Барышня»
Кластер: **air-gap regulator**. Изоляция плат, клиренс, гальваническая развязка.

### 2.5 Фитиль / «Ангел» / «Будда»
Кластер: **hold+drain bus**. Люстра-фонтан. Свеча как батарея с видимым SOC.

### 2.6 Кристалл / «Снежинка»
Кластер: **vector inverter + no-handshake**. Пакет без ACK. Zero: «нас навырезали» — фабрика вне объекта.

### 2.7 Порог / «Белый друг»
Кластер: **wrong-door as map**. Дежурный ангел = DNS без A-записи.

### 2.8 Берег / «Ассоль»
Кластер: **dead-quest detector**. Syscall `kill`, не `retry`.

### 2.9 Канал / «Уходит Бог»
Кластер: **honest-bus filter**. Drop mux, оставить одну физическую линию.

### 2.10 Пробоина / «Пьяный корабль»
Кластер: **identity-in-caliber**. Объект = сечение, не экипаж. Корабль в игле.

## 3. Инвентарь 2019 → аппараты

| предмет | аппарат | mid-level |
|---|---|---|
| кресло-лыжи | rocker-rail | oscillate+translate на одной дуге |
| вело-часы | phase-lock wheel | цепь связывает два 50/50 |
| часы-приборы | opcode dial | cut/scoop на одном такте |
| люстра-фонтан | manifold drain | fan-out бюджета |
| корабль в игле | hostile aperture | remain_one + pass_port |
| лестница-книги | index stair | walk / skip_row |
| поднос-лицо | synthesis platen | части → лицо |
| шляпа | decomposition volume | лицо → органы × 4×4 |
| банка + прищепки | runtime jar | клипсы как mutex |
| ноты на верёвках | airborne bus | пакеты на бельевой шине |

Zero = снятый интерфейс: ботинки, седло, подножка, пустой цилиндр, молчание снежинки.

---

## 4. Шляпа = таблица умножения

Пара предметов — сложение 50+50. Шляпа — n×m: поля=рот, раковина=органы, линза=4 квадрата → 16 клеток. Поднос делает обратное.

---

## 5. 50/50 внутри vs 200% между

Внутри детали только 50+50=100. 200% — между двумя полными чтениями (Дон Кихот / Санчо). Кресло-лыжи: две должности на одном ребре, пока измерение не схлопнуло уровень.

## 7. Запрещено

«всё сон», «всё символ», «всё квантовый компьютер» без имени муфты, caption вместо A/B/zero, химия мозга как единица.

Параллель законна, только если видны **одна деталь** и **два режима**.
