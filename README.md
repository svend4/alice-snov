# Алиса: Машина снов

GDD-слой **Physics of Carriers** — физика носителя для игры-капчи «Алиса Дали в стране сюрреалистических техночудес».

Не MMORPG. Премиум-3D серьёзная капча с сезоном инстансов.

Закон внутри детали: **50% + 50% = 100%**.
200% только между двумя полными чтениями (Дон Кихот / Санчо).

## Титул

Алиса ходит по техночудесной стране не чтобы проснуться, а чтобы **не убить предмет вторым названием**.

## Лицензия

Текст технического документа — свободно для чтения и доработки в этом репозитории.
Зоны описаны по **закону носителя**, не как ассеты чужих клипов.
Песни Кашина, живопись Дали/Куша — чужие права; в сборку не входят.

Бенчмарк не является медицинским тестом и не измеряет вещества мозга.
